SCOOTER RUSH 3D — VERSION 7.0

INSTALLATION ON GITHUB PAGES
1. Unzip Scooter_Rush_3D_v7.zip.
2. Upload index.html and the complete assets folder to the root of your GitHub repository.
3. The main file must be named exactly index.html.
4. Keep assets beside index.html. Do not upload only the HTML file.
5. Wait for GitHub Pages to publish, then reload the site.

WHAT'S NEW
- Your supplied motorcycle engine audio is included.
- Holding GAS makes the engine sound sharper and higher; releasing GAS returns it to its normal tone.
- Static cones and obstacles removed; moving cars now use the four road lanes.
- A collision triggers a motorcycle fall/tilt animation with sparks and an accident screen.
- City route has houses and shops; forest route has trees; coast route has palms and beach huts.
- Motorcycle models include extra brake discs, calipers and metal details.
- Hard difficulty gives more money for wins, collected coins and each kilometer in endless mode.

NOTES
- The game loads Three.js from a CDN, so an internet connection is needed.
- Progress is saved in the browser's local storage.
- Test the game on the target phone after publishing; performance depends on the device and browser.
